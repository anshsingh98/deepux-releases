# Deepux

Brightness and eye protection control for Debian, Ubuntu, and Bodhi Linux.

- **Brightness** - real hardware brightness written straight to `/sys/class/backlight`
  (your password is asked only once, then never again).
- **Eye Protection** - a warm blue-light / colour-temperature filter driven by
  `gammastep`, `redshift` or the native X11 gamma ramp.

Download the latest `.deb` file from the Releases section and double-click it to install.
